# Output Format

## Structure

使用简体中文，默认结构如下：

```markdown
日期范围：YYYY-MM-DD 至 YYYY-MM-DD（按用户时区）

**今日重点**
1. ...

**X/社区热点**
1. ...

**官方发布/技术博客**
1. 简略介绍. 链接

**补充观察**
- ...
```

可以在没有内容时省略“补充观察”，但不要省略“官方发布/技术博客”；若没有发现新内容，明确说明。

## Item Style

- 每条 1-2 句，写清“发生了什么”和“为什么值得看”。
- 官方发布或博客使用格式：`1. 简略介绍. 链接`
- X/社区热点也尽量附链接；若无法获得原帖，附最接近的一手或可信二级来源。
- 不要写空泛形容词堆叠，例如“引发广泛关注”；改写为具体影响，例如“新增 API 限额策略，影响使用成本估算”。
- 不要跨越超过两个自然日；旧背景只可作为一句补充。

## Selection Defaults

- 今日重点：3-5 条，覆盖最重要事件。
- X/社区热点：3-8 条，热点少时宁缺毋滥。
- 官方发布/技术博客：逐社区列出有新内容的条目；没有新内容的社区可合并成一句。
- 如信息冲突，说明冲突点并优先采用官方来源。
